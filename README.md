# SOOP (AfreecaTV) コメント連携プラグイン for わんコメ

[わんコメ（OneComme）](https://onecomme.com/) に、[SOOP（旧AfreecaTV）](https://www.sooplive.com/) のライブ配信コメントをリアルタイムに取り込むプラグインです。

Pure Node.js（外部ライブラリ非依存）で動作し、公式APIとセキュアなWebSocketプロトコルを使用してコメントを取得します。

---

## 主な特徴

- **ゼロ外部依存（Pure Node.js）**: `npm install` や外部モジュール不要。単体ファイルで確実に動作します。
- **リアルタイムコメント取得**: SSL/TLS経由のWebSocketでSOOPチャットサーバーと直接通信し、低遅延でコメントを受信。
- **各種イベント対応**:
  - 通常チャットコメント
  - 絵文字コメント
  - 星風船（ドネーション）
  - アドバルーン
  - サブスクリプション通知
  - 配信者・公式アナウンス
- **枠の自動検知**: わんコメ側の枠設定を自動で検知して接続・切断を同期します。

---

## 導入手順

### 1. ダウンロードと配置
1. 本リポジトリ右上の **「Code」→「Download ZIP」** からZIPをダウンロードして解凍します。
2. わんコメを開き、左上の **メニュー「≡」→「連携」→「プラグイン」** を開きます。
3. **「フォルダを開く」** をクリックします（`%APPDATA%\onecomme\plugins` が開きます）。
4. 解凍したフォルダ（フォルダ名を `soop` に変更推奨）を配置します。

フォルダ構成のイメージ:
```text
plugins/
  soop/
    plugin.js
    package.json
    README.md
    LICENSE
```

### 2. わんコメ側で枠を追加
1. わんコメの「配信」または「視聴者」一覧の **「＋」** ボタンから枠を作成します。
2. 枠の名前を **`Soop`** に設定します。
3. URL欄に、以下のいずれかの形式で入力します：
   - 通常URL: `https://play.sooplive.co.kr/あなたのBJID`
   - またはエイリアスURL: `https://mildom.com/soop/あなたのBJID`
     - ※わんコメの内蔵ブラウザ接続を回避し、プラグイン経由のダイレクト注入を安定化させる場合にエイリアスURLが推奨されます。
4. 枠のスイッチを **ON** にします。

### 3. 有効化
わんコメのプラグイン設定画面でプラグインを再読み込みするか、わんコメ本体を再起動すると自動的にSOOPチャットサーバーへ接続が開始されます。

---

## 仕様・プロトコルについて

- SOOP（旧AfreecaTV）のライブ配信チャットサーバープロトコル（ハンドシェイク・マスクフレーム・バイナリ/テキストフレームデコード）に準拠しています。
- わんコメの標準ローカルAPI（`http://localhost:11180/api/comments`）を利用して、指定されたサービス枠へコメントを安全に中継します。
